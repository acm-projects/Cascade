Cascade

Quick-look page for exercising the trends and video-search features together. Not the final UI.

Renders hormozi / minimalist / bold_viral / cinematic caption styles. Note: there's currently no endpoint to download/view the finished clips, so this just shows the filenames once done — they're written to disk on the server (backend/clips/) rather than served over HTTP.

An LLM agent searches the video's embeddings, inspects candidates, and suggests clips. Confidence (0–1) is the model's own estimate of how well a clip fits the category, based on the frames and transcript it inspected. It is not a measured score, so use it to compare clips within one run, not across videos.
